# LSTM learn — notebook และข้อมูลเทรน

โฟลเดอร์นี้เก็บขั้นตอนการพัฒนาโมเดลจับท่า ตั้งแต่ฝึกตาม tutorial จนถึงโมเดลที่เกมใช้

## ไฟล์

| ไฟล์ | คืออะไร | เกมใช้ไหม |
|---|---|---|
| `Classification_Pose.ipynb` | เก็บข้อมูลท่ามวยจากกล้อง สร้าง feature ทดลองเทรน LSTM และทดสอบสด | ต้นแบบของโมเดลที่ใช้ |
| `MP_Data_Diag/` | ข้อมูลเทรนชุดปัจจุบัน — 4 session × 6 ท่า × 15 คลิป × 36 เฟรม | ✅ ใช้เทรน |
| `MP_Data_Pose/` | ข้อมูลชุดแรก คลิปละ 16 เฟรม — ภายหลังเปลี่ยนมาเก็บคลิปละ 36 เฟรมใน `MP_Data_Diag` | ❌ |
| `LSTM-learn.ipynb` | **tutorial ภาษามือ** (`hello` / `thanks` / `iloveyou`) ที่ใช้เรียนรู้ MediaPipe + LSTM ก่อนเริ่มทำโปรเจกต์ | ❌ |
| `OpenCV_Learning.ipynb` | ฝึกใช้ OpenCV ตรวจจับวัตถุจากภาพนิ่งและจากกล้อง | ❌ |

ไฟล์ `../action.h5` คือโมเดลที่ได้จาก `LSTM-learn.ipynb` — เป็นโมเดลภาษามือ ไม่ใช่โมเดลมวย

## ⚠️ ตัวเลขใน `Classification_Pose.ipynb` ไม่ใช่ตัวเลขของโมเดลที่เกมใช้
