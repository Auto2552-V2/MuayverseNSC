### สิ่งที่พบตอนย้าย

**1. โมเดลที่อยู่ในรีโปเป็นโมเดลที่ยังไม่เทรน**

`train_model.py` เดิมวาง `siamese_model.save()` กับการแปลง TFLite ไว้ "นอก"
`if __name__ == "__main__"` ดังนั้นทุกครั้งที่ `main.py` ทำ `from train_model import ...`
โมเดลน้ำหนักสุ่มจะถูกเขียนทับไฟล์ที่เทรนแล้ว แล้ว `main.py` ก็โหลดน้ำหนักสุ่มนั้นมาเสิร์ฟ
วัดได้ว่า `siamese_model.tflite` และ `jab_model/siamese_model.tflite` ที่ commit ไว้
ได้ความแม่น 49-56% (= เท่าเดา) — แก้แล้ว ย้ายการเซฟเข้าไปใน `__main__`

**2. `validation_split=0.2` วัดอะไรไม่ได้**

`y.npy` เรียง 783 ตัวแรกเป็นคลาส 1 ที่เหลือเป็นคลาส 0 และ Keras ตัด 20% ท้าย
โดยไม่สุ่ม → validation เป็นคลาส 0 ล้วน ตัวเลข val ที่เคยเห็นจึงไม่มีความหมาย
แก้แล้ว สุ่มสลับก่อนแบ่ง ผลจริง:

| ชุด | acc @ threshold 0.3 |
|---|---|
| train (1,252 คู่) | 92.9% |
| validation (314 คู่) | 89.2% |

**3. เกณฑ์ตัดสินใน `main.py` สามข้อไม่ตรงกับข้อมูล** (หน้าเว็บแก้แล้ว `main.py` ยังไม่)

- `percent = ... * 2` ทำให้ค่าทะลุ 100 ไปถึง 200 ได้
- เงื่อนไข `30 <= elbow_angle <= 50` เป็นจังหวะกลางทางของการเหวี่ยง ไม่ใช่จังหวะหมัดยืด
  (วัดจากคลิปต้นแบบ: ยืดสุด 173-177° ตั้งการ์ด 2-39°) จึงแทบไม่เคยเข้าเงื่อนไข
- `dx` เทียบผลต่างต่อ "เฟรม" กับค่าคงที่ ซึ่งผูกกับ fps ของเครื่อง เครื่องเร็วกว่า
  ได้ค่าน้อยกว่าทั้งที่ชกแรงเท่ากัน

**4. การเทียบกับ "ทุกเฟรมในคลิปต้นแบบ" ทำให้ท่าอะไรก็ผ่าน**

คลิปต้นแบบครอบทั้งวงจรการ์ด → ออกหมัด → กลับการ์ด การหา "ระยะที่ใกล้ที่สุด"
ในทุกเฟรมจึงทำให้การยืนตั้งการ์ดเฉย ๆ ได้ 100% หน้าเว็บคัดเหลือ 22 เฟรมที่ยืด ≥150°

**5. ไม่มีด่านกรอง "ไม่มีคนในเฟรม"**

embedding เสื่อมนอกช่วงข้อมูลที่เทรน ป้อน noise สุ่มหรือเวกเตอร์ศูนย์ได้ระยะ 0.004
= 99% หน้าเว็บเพิ่มด่าน cosine ขั้นต่ำ 0.5 (ท่าคนจริง 0.57-1.00 · noise 0.10 · ศูนย์ 0.00)

## วิธีการ

### ชุดข้อมูล

ไม่มีชุดข้อมูลท่ามวยไทยที่ใช้งานได้อยู่ก่อน จึงเก็บข้อมูลท่ามวยจากครูมวยไทยในพื้นที่เอง
เพื่อใช้เป็นท่าต้นแบบ

### ปัญหาเรื่องสัดส่วนร่างกาย

ผู้ฝึกแต่ละคนมีความสูงและสัดส่วนต่างกัน ถ้าเปรียบเทียบพิกัดข้อต่อตรง ๆ ระบบจะตัดสินจาก
**ขนาดตัว** แทนที่จะตัดสินจาก **ท่าทาง** คนตัวเล็กที่ทำท่าถูกจะได้คะแนนต่ำกว่าคนตัวใหญ่
ที่ทำท่าผิด

แก้ด้วยการทำ normalization ปรับสัดส่วนร่างกายให้อยู่บนมาตรฐานเดียวกันก่อนเปรียบเทียบ

### การให้คะแนน

ใช้ **Siamese network** ซึ่งเรียนรู้ที่จะวัดความคล้ายระหว่างท่าสองท่า แทนที่จะจำแนกว่า
เป็นท่าอะไร ข้อดีคือเพิ่มท่าใหม่ได้โดยไม่ต้องเทรนโมเดลใหม่ เพียงเพิ่มท่าต้นแบบเข้าไป

ผลลัพธ์ออกมาเป็นเปอร์เซ็นต์ความคล้ายกับท่าต้นแบบ

### คำแนะนำแก้ท่า

ส่งผลการเปรียบเทียบเข้าโมเดลภาษาเพื่อแปลงตัวเลขให้เป็นคำแนะนำที่ผู้ฝึกเข้าใจได้ทันที
